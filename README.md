# Menú de Colmado

## Descripción del programa

Este programa fue desarrollado para simular un pequeño sistema de ventas de un colmado. Su funcionamiento es sencillo: el usuario selecciona un producto desde un **ComboBox**, escribe la cantidad que desea comprar en un **TextBox** y elige la forma de pago mediante los **RadioButton**, ya sea en efectivo o con tarjeta.

Al hacer clic en el botón **Calcular**, el programa toma el precio del producto seleccionado, lo multiplica por la cantidad ingresada y muestra el total a pagar en un **Label**. Además, si el cliente paga en efectivo, se aplica automáticamente un descuento del **5%**, lo que permite observar cómo se utilizan las estructuras condicionales dentro del programa.

También se incluyó una validación para evitar que el usuario ingrese datos incorrectos en la cantidad, mostrando un mensaje si el valor no es válido. Con este proyecto pude poner en práctica el uso de controles de **Windows Forms**, eventos, variables, condicionales y algunos conceptos básicos de la **Programación Orientada a Objetos**, creando una aplicación simple, funcional y fácil de utilizar.

## Funcionalidades

- Seleccionar un producto.
- Ingresar la cantidad a comprar.
- Elegir la forma de pago.
- Calcular el total de la compra.
- Aplicar un descuento por pago en efectivo.
- Validar la entrada de datos.

## Tecnologías utilizadas

- C#
- Windows Forms (.NET)
- Visual Studio 2022
